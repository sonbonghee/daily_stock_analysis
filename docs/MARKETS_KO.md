# 미국·한국·일본 주식 분석

홈의 기본 시장 동향 분석 대상은 미국·한국·일본입니다. 시장 선택 메뉴에서 개별 시장 또는 서버 기본값을 선택할 수 있습니다. 기존 다른 시장의 분석 기록과 백엔드 기능은 유지합니다.

| 거래소 선택 | 입력 예시 | 분석 코드 | 통화 |
|---|---|---|---|
| 미국 | AAPL | AAPL | USD |
| KOSPI | 005930 | 005930.KS | KRW |
| KOSDAQ | 247540 | 247540.KQ | KRW |
| 일본 | 7203 | 7203.T | JPY |

자동 모드에서는 거래소 접미사가 있는 완전한 코드 또는 미국 티커를 사용합니다. 숫자만으로 시장을 추측하지 않습니다. 종목명은 검색 결과에서 선택하세요. 홈 자동완성은 US/KR/JP 종목만 표시하며, 종목 코드를 다른 거래소에 제출하는 실수를 막습니다.

신규 설치 예시는 AAPL, MSFT, 삼성전자, SK하이닉스, 도요타, 소니입니다. 투자 추천이 아닙니다. 기존 설치의 관심 종목·모델·API 키는 덮어쓰지 않습니다. 기존 서버의 정기 시장 분석 대상도 변경하려면 설정에서 `MARKET_REVIEW_REGION=us,kr,jp`를 저장하세요. 한국어 보고서 설정은 유지합니다.

거래일과 휴장일은 기존 거래소 캘린더 및 현지 시간대를 사용합니다. 미국 서머타임을 고정 한국시간으로 계산하지 않습니다. 한국·일본 시세와 기초 재무자료는 기존 Yahoo Finance 경로를 사용하며 지연 또는 누락될 수 있습니다.

한국·일본의 시장 전체 상승·하락 종목 수, 업종 순위, 시장 신호 알림과 JPY·KRW 포트폴리오 환율·평가액은 아직 완전 지원하지 않습니다. 화면에 없는 값을 0이나 정상 상태로 해석하지 마세요. 자동 분석 일정과 외부 알림은 별도 설정이 필요합니다.

이 문서는 한국어 배포 버전의 변경 사항을 다룹니다. 원본 중문·영문 문서는 상위 프로젝트 공통 기능 설명으로 유지합니다. 배포·인증·복구는 [운영 안내](DEPLOY_KO.md)를 참고하세요.
